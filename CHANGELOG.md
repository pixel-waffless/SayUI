# Changelog

All notable changes to SayUI are documented in this file.

## 1.0.2

- Cleaned up broken and placeholder demo links and image references.
- Replaced unknown third-party demo imagery with safe, repository-owned SVG assets.
- Added static HTML and accessibility validation for public examples.
- Added reduced-motion support for public `ui-*` transitions and animations.
- Hardened CI and tag-driven publishing with reproducible validation and tag/version matching.
- Moved internal process notes out of the primary documentation path and clarified public usage guidance.
- Expanded package-content validation while keeping the release focused on maintenance and presentation quality.

## 1.0.1

- Renamed the npm package to `sayu-ui` and aligned the public SayUI branding and package metadata.
- Updated installation, CSS, Sass, and package-content documentation for the published package.

## 1.0.0

- Published the first stable framework-agnostic HTML, SCSS, and compiled CSS release.
- Included the documented `ui-*` component and layout contracts, editorial demos, and package exports.
